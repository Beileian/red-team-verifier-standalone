# Wolfram 计算不可约性 · 评审方法论参考

来源: 新智元《20岁拿下博士、答辩席坐着费曼的狂人：AI是第一种「外星智能」》(2026-07-26)
全面评审日期: 2026-07-26

## 对全面评审的方法论影响

### 1. 天气模式 → 多层防御的哲学根基

Wolfram 的类比："像对天气一样对AI——不预测，建堤防"。

**对应隐序架构**:
- output-integrity-gate = 防洪堤（硬门禁）
- red-team-verifier = 预警系统（独立审查）
- 三路并行 = 多模型交叉验证（"AI society > 单一AI"）
- gold test = 堤防定期检修

评审时提问："这条建议假设AI可以被预测纠错，还是承认不可约性并建防御？"

### 2. 计算不可约口袋 → 评审精度边界

Wolfram：AI只能在"可约口袋"里精确——有规律可循的小角落。滑出口袋=全盲。

**对评审的约束**：当被评审对象涉及高度路径依赖、正反馈循环、多层博弈时（如市场走势、政策连锁反应），标注"处于不可约盲区"——不是信息不足，是系统本质不可预测。

### 3. 外星智能 → 评审的认知局限

LLM 的内部表征与人类语言不共享概念空间。评审时注意：
- "AI为什么这么判断"可能不被压缩到一句话里
- 红队批判的"推理错误"有时可能只是"AI用了我们没命名的概念"
- 不要假设AI的认知结构与人类相同

### 4. 驳论：不可约非绝对

Sornette 的反对声音：换尺度描述→混沌变清楚。映射到评审：当三路审查全错时，可能不是审查不够，是审查的"描述尺度"不对——需升级到更高层级的框架思考。
