# Karpathy LLM Council 匿名互评模式

**来源**: karpathy/llm-council · 23.1k⭐ · 2026-07-25 全面评审

## 核心设计

三段架构：
1. **Stage 1**: 所有模型并行回答同一问题
2. **Stage 2**: 每个模型匿名审查其他人的回答（"Response A/B/C"），强制排序
3. **Stage 3**: Chairman 综合所有意见输出最终答案

## 关键创新

**匿名互评防止偏袒**。Stage 2 把各模型产出标注为"Response A/B/C"，评审者不知道哪份是自己的，无法偏袒自己。

## 对我们的启发

当前三路审查链：
```
红队 → 反共识(读红队) → 宏观(读红+反) → 合成
```

加入匿名互评后：
```
红队 → 反共识(读红队) → 宏观(读红+反) → 
  🆕 三路匿名互评：每个模型拿到其他两路的产出(标注为"审查A/B/C")，做互评排名
  → 合成器基于排名权重做最终合成
```

技术上只需改合成审查 cron 的 prompt——在合成前加一段互评指令。不需要新模型、新 cron、新 API。

## 已知限制

- LLM-as-judge 有系统性偏差（偏好 verbose 回答、position bias）
- Chairman 是单点——如果选错模型，整个输出被污染
- 本实现是单模型角色扮演（非真正的多模型并行），需标注「⚠️ 单模型模拟」
