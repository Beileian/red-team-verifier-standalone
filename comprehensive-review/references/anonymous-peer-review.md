# 匿名互评模式（llm-council 萃取, 2026-07-25）

> 来源：Karpathy llm-council GitHub（23.1k⭐）+ 本地评审

## 核心模式

Karpathy 的 LLM Council 三段架构中，Stage 2（匿名互评）是最具迁移价值的机制：

```
Stage 1: 多模型并行回答 → Stage 2: 匿名互评排名 → Stage 3: Chairman 合成
```

匿名化（"Response A/B/C"）防止模型偏袒自己或特定模型。

## 到三路审查的映射

我们的三路审查（红队/反共识/宏观）当前只有角色分工，没有互评环节。映射：

```
红队 → 反共识(读红队) → 宏观(读红+反) → 合成
  ↓ 🆕
匿名互评：合成前，将三路产出匿名化为"审查A/B/C"→ 每路评价其他两路 → 加权合成
```

## 实现

只需改合成审查 cron 的 prompt 一行：
- 将红队/反共识/宏观产出标注为"审查 A/B/C"
- 让合成模型先做互评排名
- 基于排名加权再做最终合成

零新基础设施。P1 留存待执行。

## 风险

LLM-as-judge 已知偏差：偏好 verbose 回答、position bias、偏好自己风格。匿名化解决了一部分，但不是全解。Chairman 仍是单点。
